# Akash Pandey Portfolio

Single-page portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static production files will be generated in `dist/`.

## Before deploying

1. Replace `akash@example.com` in `src/components/Contact.jsx` with Akash's real email.
2. Replace `+91 XXXXX XXXXX` with the real phone number.
3. Add real GitHub and LinkedIn profile URLs in `src/components/Footer.jsx`.
4. Replace the project preview placeholders in `src/components/Projects.jsx` with optimized screenshots. Use fixed aspect ratios and `loading="lazy"` on images.
5. Confirm the internship dates and update `src/components/Experience.jsx` if desired.

## Deployment

Works as a static Vite build on Netlify, Vercel, Cloudflare Pages, GitHub Pages (with the appropriate Vite base setting), or any static host.
